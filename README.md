Smart Student Expense & Budget Tracker
A simple, responsive web application that helps students track their income, expenses, and monthly budget in one place. The project is built using HTML, CSS, and JavaScript, with LocalStorage for saving data in the browser and Chart.js for visual reports.
✨ Features
- Dashboard Overview – View total balance, total income, total expenses, and monthly budget.
- Add Transactions – Record income and expenses with a title, amount, category, and date.
- Delete Transactions – Remove transactions that are no longer needed.
- Monthly Budget Planner – Set a monthly budget and monitor spending, remaining balance, and progress.
- Search Transactions – Search transactions by title or category.
- Filter Transactions – Show all transactions, income only, or expenses only.
- Expense Chart – View spending by category using a doughnut chart.
- Monthly Chart – Compare income and expenses across months.
- CSV Export – Download transaction records as a CSV file.
- Dark / Light Mode – Switch themes, with the selected theme saved in the browser.
- Responsive Layout – Use the dashboard on desktop, tablet, and mobile screens.

🚀 Getting Started
Run locally
1. Clone this repository:
   git clone https://github.com/Chitranshchauhan/Smart-Student-Expense-Budget-Tracker.git
2. Open the project folder:
   cd Smart-Student-Expense-Budget-Tracker
3. Open index.html in your browser.
   Alternatively, open the folder in Visual Studio Code and run index.html using the Live Server extension.
An internet connection is required to load the Chart.js library from its CDN.

💡 How to Use
1. Open the application in your browser.
2. Add an income or expense using the Add Transaction button.
3. Enter the transaction details and save.
4. View updated totals and charts on the dashboard.
5. Set a monthly budget in the Budget Planner section.
6. Use search and filters to find specific transactions.
7. Export your transaction data using Export CSV.
8. Switch between dark and light themes using the theme button.
💾 Data Storage
This version stores data in the browser's LocalStorage. Your transactions and budget are saved on the device and browser where you use the application. Clearing browser site data or using a different browser/device may remove or not show the saved data.
